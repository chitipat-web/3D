# Kawasaki Ninja ZX-6R 2019 — โมเดล 3 มิติ

โมเดล 3 มิติของ **Kawasaki Ninja ZX-6R ปี 2019 (ZX636G)** สร้างด้วยโค้ด three.js ทั้งคัน
ไม่ได้ใช้ไฟล์โมเดลหรือรูปภาพจากภายนอก สัดส่วนอิงจากสเปกจริงของรถ

## ไฟล์ที่ใช้งานได้ทันที

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `models/kawasaki-zx6r-2019.glb` | โมเดลสี KRT Edition (Lime Green / Ebony) เปิดได้ใน Blender, Windows 3D Viewer, https://gltf-viewer.donmccurdy.com ฯลฯ |
| `models/kawasaki-zx6r-2019-gray.glb` | โมเดลสี Pearl Storm Gray / Metallic Spark Black |
| `index.html` | หน้าเว็บดูโมเดลแบบหมุนได้ เปลี่ยนสี ดูเส้นบอกขนาด เปิด/ปิดไฟ บันทึก PNG และ GLB |

ไฟล์ GLB ใช้หน่วยเมตร ขนาดจริง (แกน +X ไปทางหน้ารถ, +Y ขึ้นบน) ประมาณ 175,000 สามเหลี่ยม แยกชิ้นส่วนตามชื่อ
เช่น `FrontWheel`, `FrontFork`, `Engine`, `Exhaust`, `Bodywork` เพื่อให้แก้ไขต่อได้ง่าย

## เปิดหน้าดูโมเดลในเครื่อง

```bash
npm install          # ติดตั้ง three.js สำหรับเครื่องมือ (หน้าเว็บโหลด three.js จาก CDN เอง)
npm run serve        # แล้วเปิด http://localhost:8080
```

## สเปกที่ใช้สร้างโมเดล

| รายการ | ค่า |

| กำลังสูงสุด | 130 PS @ 13,500 rpm (136 PS เมื่อมี ram air) |
| แรงบิดสูงสุด | 70.8 N·m @ 11,000 rpm |

| มุมคอ / เทรล | 24.5° / 103 mm |
| ยาง | หน้า 120/70 ZR17, หลัง 180/55 ZR17 |

ขนาดกล่องครอบของโมเดลที่ได้: 2,015 × 719 × 1,098 mm (ต่างจากสเปกไม่เกิน 1.3%)

## รายละเอียดที่สร้างไว้

- **ด้านหน้า**: หน้ากากทรง "pug nose" ของปี 2019, ไฟหน้า LED คู่พร้อมไฟหรี่, ช่อง ram-air, ชิลด์ใส, กระจกมองข้าง, ไฟเลี้ยวบนแฟริ่ง
- **ช่วงล่าง**: โช้คหัวกลับ, แผงคอบน–ล่าง, จานเบรกทรงดอกไม้แบบเจาะรู, คาลิปเปอร์เรเดียล, สายเบรก, ล้อ 6 ก้าน, ยางพร้อมลายดอก
- **ตัวรถ**: ถังน้ำมัน, เบาะคนขับและคนซ้อน, ท้ายทรงเหลี่ยมพร้อมไฟท้าย LED, ท้ายสั้นยึดป้ายทะเบียน, ไฟเลี้ยวหลัง
- **เครื่องยนต์และโครง**: เฟรมอะลูมิเนียม, ซับเฟรม, สวิงอาร์ม, โช้คหลังพร้อมสปริง, เครื่อง 4 สูบ, หม้อน้ำ, เฮดเดอร์ 4 ท่อ, หม้อพักใต้เครื่อง, ปลายท่อด้านขวา, โซ่และสเตอร์ 15/43 ฟัน, เกียร์โยง, ขาตั้งข้าง
- **สีและลาย**: KRT Edition และ Pearl Storm Gray วาดลายด้วย canvas ในโค้ด

## โครงสร้างโค้ด

```
src/
  layout.js     ขนาดหลักและเรขาคณิตของคอรถ (rake/trail/offset)
  geom.js       เครื่องมือสร้างพื้นผิว: loft, lathe, sweep, extrude
  chassis.js    ล้อ ยาง เบรก โช้คหน้า แฮนด์
  frame.js      เฟรม สวิงอาร์ม โช้คหลัง โซ่ พักเท้า
  engine.js     เครื่องยนต์ หม้อน้ำ ท่อไอเสีย
  body.js       แฟริ่ง ไฟหน้า ชิลด์ ถัง เบาะ ท้าย บังโคลน
  decals.js     ลายสติกเกอร์ หน้าปัด ไฟหน้า (วาดด้วย canvas)
  materials.js  วัสดุและชุดสี
  studio.js     แสงและฉากสตูดิโอ
  viewer.js     หน้าเว็บดูโมเดล
tools/
  render.mjs        เรนเดอร์ภาพนิ่งด้วย Chromium แบบ headless
  export-glb.mjs    ส่งออกไฟล์ GLB  (node tools/export-glb.mjs [krt|gray])
  build-artifact.mjs  รวมหน้าเว็บเป็นไฟล์เดียว
```
